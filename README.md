## About

I'm a 15-year-old developer from Egypt who is driven mostly by curiosity.

When something catches my attention, I usually want to know how it works rather than just how to use it. I dislike shallow understanding, so I tend to keep digging, experimenting, taking things apart, rebuilding them, and learning from whatever breaks along the way.

I work across several areas at the same time: software engineering, algorithms, Linux and systems, Minecraft infrastructure, hardware, virtualization, and practical AI-assisted development.

I also have a habit of over-engineering things. Sometimes that is useful, sometimes it is completely unnecessary. Either way, I usually learn something from it.

## The Rabbit Hole

A lot of my projects start from a very small question.

Then I start digging.

A simple script can turn into a server, a tool can turn into a whole system, and a random technical idea can turn into an experiment involving containers, virtual machines, hardware, or a completely different field.

I like following those ideas as far as they go, especially when different areas start connecting. I don't always take the shortest route, and sometimes I absolutely build the thing that didn't need to exist — but that's often where I learn the most.
